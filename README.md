# 言語課題ランナー

言語流暢性課題と動詞生成課題の旧版・改訂版，計 4 パターンを選択・並べ替えて実施する Web アプリです．HTML，CSS，JavaScript のみで動作します．記録はサーバーへ送信せず，端末のブラウザ内に保持します．

## 課題構成

| 課題名 | 1 セット | セット数 | 合計 |
|---|---|---:|---:|
| 言語流暢性課題 | 単語生成 15 秒 → 休憩 15 秒 → 無意味語反復 15 秒 → 休憩 15 秒 | 6 | 6 分 |
| 動詞生成課題 | 動詞生成 30 秒 → 休憩 30 秒 → 名詞反復 30 秒 → 休憩 30 秒 | 6 | 12 分 |
| 言語流暢性課題（改） | 単語生成 15 秒 → 休憩 15 秒 | 12 | 6 分 |
| 動詞生成課題（改） | 動詞生成 30 秒 → 休憩 30 秒 | 6 | 6 分 |

動詞生成と名詞反復では 5 名詞を 6 秒ずつ提示します．各課題の最終休憩も課題時間に含みます．開始前・終了後の独立した安静・基準値取得は設けません．課題間に別途 0〜600 秒の休憩を設定でき，初期値は 60 秒です．改訂版 2 課題の初期選択では合計 13 分です．全 4 課題では 33 分です．

旧版は会話で設定した予備実験用の旧構成を意味し，先行研究のプロトコルの完全な再現を意味しません．改訂版は会話で合意した設定です．

## 使用方法

1. メイン画面でチェックを入れた課題だけを実行します．上下の矢印で並べ替えます．実行順番号と右側の一覧・合計時間が更新されます．
2. 参加者 ID，課題間の休憩，全画面表示，実行中の時間表示，メモを設定します．
3. 「刺激・構成」で提示語を確認・編集できます．単語数と文字数が構成に一致しない場合は保存できません．
4. 説明を確認し，準備完了にチェックを入れて本番を開始します．生成・反復・休憩を画面の見出しで区別します．途中に追加の説明時間はありません．
5. 終了後にイベント CSV と全記録 JSON をダウンロードします．

`index.html` をローカルで開いても利用できます．同じフォルダに `style.css`，`protocol.js`，`app.js` を置いてください．追加インストールは不要です．PC のブラウザを推奨します．

## 刺激

旧言語流暢性課題の初期文字は「あ，か，き，さ，た，は」です．改訂版は「あ，か，き，さ，た，は，な，ま，や，ら，み，こ」の 12 文字です．初期名詞リストは会話中の提案を使用します．これらは難易度・親密度などを統制した標準刺激セットではなく，予備検証用の初期案です．両版を連続実施すると文字・名詞が重複するため，必要に応じて刺激を編集し，課題順序を入れ替えてください．編集済み刺激はセッション開始時に固定し，JSON に記録します．

## 時刻とイベント CSV

| 列・値 | 意味 |
|---|---|
| `event = task_start` | 各課題の最初の生成刺激の開始．1 課題につき 1 行です． |
| `event = task_end` | 課題の最終休憩を含む終了． |
| `event = phase_start / phase_end` | 各文字・名詞・休憩区間の開始・終了． |
| `event = pause / resume` | 一時停止・再開と理由・停止時間． |
| `event = task_abort / session_abort` | 未完了の課題・セッションの中止． |
| `task_name` | 画面と同じ課題名．（改）の有無で区別します． |
| `task_order` | 選択課題のみを数えた実行順． |
| `task_id` | `vf_original`，`vg_original`，`vf_revised`，`vg_revised`． |
| `timestamp` | 開始時の OS 時刻と単調時計を対応付けた UTC ISO 8601 時刻． |
| `timestamp_jst` | 同時点の日本時間（`+09:00`）． |
| `timestamp_unix_ms` | 同時点の UNIX 時刻（ミリ秒）． |
| `wall_clock_unix_ms` | イベント発生時に別途取得した `Date.now()`．時計補正の検討に使用できます． |
| `elapsed_ms` | セッション開始からの経過時間．一時停止を含みます． |
| `active_elapsed_ms` | 一時停止を除く経過時間． |
| `cycle / stimulus_index / stimulus` | セット番号，名詞のセット内番号，提示刺激． |
| `planned_onset_ms / planned_duration_ms` | 予定の開始位置・長さ． |
| `actual_duration_ms / wall_duration_ms` | 区間終了時の実際の長さ．前者は停止を除き，後者は停止を含みます． |
| `onset_delay_ms / overrun_ms` | 予定からの開始遅延・区間の超過時間． |
| `interrupted` | 停止を挟んだ区間の終了イベントで `true`． |

CSV は UTF-8 BOM 付き，CRLF 改行です．全セルを引用符で囲みます．利用者入力が表計算ソフトの数式として実行されないよう，先頭に `= + - @` を含む文字列をエスケープします．値は JSON では元の文字列で保存します．

画面上の開始時刻一覧は `task_start` イベントから生成します．外部センサとの対応付けには `timestamp_unix_ms` または JST 時刻を使用し，両端末の OS 時計を合わせてください．アプリから外部センサへの同期信号や BLE 通信は実装していません．

## 進行・一時停止・中止

`requestAnimationFrame` と `performance.now()` で時間管理します．表示更新時点をイベントとして記録し，次の刺激をその時点から規定時間提示します．遅れを取り戻すために刺激を飛ばす処理はしません．イベント時刻は物理的な発光時刻の保証ではありません．

タブ非表示，ウィンドウからのフォーカス移動，全画面解除，1 秒を超えるフレーム遅延で自動停止します．Space キーまたはボタンでも停止・再開できます．停止中は刺激を覆い，時間を進めません．再開は手動です．中止確認をキャンセルしても停止状態を維持します．中止した場合も，提示済み区間と未完了区間の記録を出力できます．

設定と最新 1 セッションを `localStorage` に保持します．各区間開始・停止・再開・終了時に保存します．保存できない場合は画面で通知します．再読み込み後は未完了のセッションを再開せず，最後に保存できた時点までの記録を確認・出力します．生成語の内容・数・正誤は取得しません．

## ファイルと検証

- `index.html`：設定・課題・結果画面．
- `style.css`：表示．
- `protocol.js`：4 パターンの提示計画，状態管理，時刻，CSV．ブラウザと Node.js で利用できます．
- `app.js`：操作・画面・端末内保存・ダウンロード．
- `tests/protocol.test.cjs`：課題時間，順序，開始イベント，停止・再開，中止，遅延，CSV を検証．

```sh
node --test tests/protocol.test.cjs
```
