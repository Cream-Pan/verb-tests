# 言語課題ランナー WebApp

言語課題ランナー WebApp は，言語流暢性課題と動詞生成課題の旧版・改訂版，計 4 パターンを選択し，指定した順番で自動実行する Web アプリケーションである．各課題の開始・終了，文字や名詞の提示，休憩，一時停止・再開の時刻を記録する．

課題名は「言語流暢性課題」「動詞生成課題」「言語流暢性課題（改）」「動詞生成課題（改）」である．改訂版 2 課題を選択し，課題間に 1 分の休憩を設定した場合の予定所要時間は 13 分である．開始前・終了後の独立した安静・基準値取得は設けない．

HTML，CSS，JavaScript で構成し，PC のブラウザからローカルで利用できる．記録はブラウザ内に保持し，イベント CSV と全記録 JSON として保存できる．アプリのバージョンは `1.0.0` である．

## プロジェクトについて

本アプリは，言語課題に伴う左右耳内温度などの生理計測データと，課題の実施時刻を対応付けるために使用する．発話・筆記・回答ボタンの操作を伴わず，参加者は画面の指示に従って頭の中で取り組む．

| 条件 | 参加者の行動 | 画面表示の例 |
|---|---|---|
| 単語生成 | 表示されたひらがなから始まる単語を，できるだけ多く頭の中で考える． | あ |
| 動詞生成 | 表示された名詞から連想できる動詞を頭の中で考える． | りんご |
| 無意味語反復 | 表示された無意味語を頭の中で繰り返す．旧言語流暢性課題のみ． | ぱぬ |
| 名詞反復 | 表示された名詞を頭の中で繰り返す．旧動詞生成課題のみ． | みかん |
| 休憩 | 生成・反復をやめ，注視点を見て休む． | ＋ |

**1 区間**は，1 つの文字・名詞・無意味語を提示する時間，または 1 回の休憩を指す．**1 セット**は，生成と休憩，旧版ではさらに反復と休憩を含む一まとまりを指す．**1 課題**は，選択した 1 パターン全体を指す．**セッション**は，選択した課題と課題間の休憩の全体を指す．

本アプリが取得するのは刺激提示と進行の履歴である．想起した語の内容・個数，正答率，反応時間は取得しない．外部センサとの接続機能や，左右半球の優位性を判定する機能は実装していない．

## ファイル構成

配布 ZIP の `verb-tests` フォルダには，以下のファイルを配置する．

| ファイル | 内容 |
|---|---|
| `index.html` | メイン画面，課題画面，結果画面，各種ダイアログを定義する． |
| `style.css` | レイアウト，文字刺激，注視点，ボタン，結果表，全画面時の表示を定義する． |
| `protocol.js` | 4 パターンの課題定義，提示計画，進行・一時停止，イベント時刻，CSV 出力を処理する． |
| `app.js` | 課題の選択・並べ替え，設定，刺激の編集，画面更新，端末内保存，ダウンロードを処理する． |
| `README.md` | 本アプリの仕様と使用方法を記載する． |
| `tests/protocol.test.cjs` | 課題時間，順序，停止・再開，開始イベント，CSV などを検証する． |

`index.html`，`style.css`，`protocol.js`，`app.js` は同じフォルダに配置する．通常の利用にはパッケージのインストールやビルドは不要である．Node.js は自動テストを実行する場合に使用する．

公開用ソースリポジトリでは，アプリの 4 ファイルを `dist/` に配置する．リポジトリからローカルで開く場合は `dist/index.html` を使用する．配布 ZIP は，同じアプリのファイルを `verb-tests/` の直下に配置した構成である．

## 利用する Web API

本アプリでは外部 JavaScript ライブラリを使用せず，ブラウザ標準の機能を利用する．

| 機能 | 用途 |
|---|---|
| SVG | 操作ボタンなどのアイコンを表示する．文字刺激と注視点は HTML のテキストとして表示する． |
| `requestAnimationFrame` | 描画更新に合わせて課題の進行を管理する． |
| Performance API | `performance.now()` によって単調増加する経過時間を取得する． |
| `Date` | 経過時間と OS 時計を対応付け，UTC・日本時間・UNIX 時刻を記録する． |
| Web Storage API | `localStorage` に設定と直近のセッション記録を保存する． |
| Fullscreen API | 開始時の全画面表示と，全画面解除の検出に使用する． |
| Page Visibility API | タブが非表示になったことを検出する． |
| `focus`・`blur` 関連機能 | フォーカスの有無を確認し，ウィンドウからフォーカスが外れた場合に停止する． |
| Blob・URL API | CSV と JSON のダウンロードファイルを生成する． |
| HTML `dialog` 要素 | 説明，刺激編集，中止確認，記録仕様のダイアログを表示する． |

ローカル版の課題実施とデータ出力にインターネット接続は不要である．公開版へのアクセス，本 README の技術バッジの表示，参考文献リンクの閲覧には接続を使用する．

## 課題条件

| 課題名 | 識別子 | 1 セットの構成 | セット数 |
|---|---|---|---:|
| 言語流暢性課題 | `vf_original` | 単語生成 15 s → 休憩 15 s → 無意味語反復 15 s → 休憩 15 s | 6 |
| 動詞生成課題 | `vg_original` | 動詞生成 30 s → 休憩 30 s → 名詞反復 30 s → 休憩 30 s | 6 |
| 言語流暢性課題（改） | `vf_revised` | 単語生成 15 s → 休憩 15 s | 12 |
| 動詞生成課題（改） | `vg_revised` | 動詞生成 30 s → 休憩 30 s | 6 |

### 言語流暢性課題

1 つのひらがなを 15 s 提示する．参加者はその文字から始まる単語をできるだけ多く頭の中で考える．同じ単語の繰り返しと，人名・地名は避ける．旧版の反復区間では，初期設定の無意味語「ぱぬ」を 15 s 提示する．

### 動詞生成課題

生成区間では，名詞を 6 s ごとに切り替え，30 s の間に 5 個提示する．参加者は各名詞から連想する動詞を頭の中で考える．1 つでも複数でもよい．例えば「りんご」では「食べる」「むく」「切る」などを想起する．

旧版の名詞反復区間でも，別の 5 名詞を 6 s ずつ提示する．参加者は名詞を頭の中で繰り返し，動詞は考えない．改訂版は名詞反復を設けない．

## 課題の進行と所要時間

開始前の説明を確認して「本番を開始」を押すと，選択した課題を設定順に自動実行する．計測中に追加の指示画面や空白時間は挿入しない．

| 課題名 | 生成時間の合計 | 反復時間の合計 | 課題内の休憩時間 | 課題全体 |
|---|---:|---:|---:|---:|
| 言語流暢性課題 | 90 s | 90 s | 180 s | 360 s／6 分 |
| 動詞生成課題 | 180 s | 180 s | 360 s | 720 s／12 分 |
| 言語流暢性課題（改） | 180 s | 0 s | 180 s | 360 s／6 分 |
| 動詞生成課題（改） | 180 s | 0 s | 180 s | 360 s／6 分 |

各課題の最後の休憩も，その課題の所要時間に含む．別途設定する課題間の休憩は，前の課題が最後の休憩まで終了した後に追加する．

| 選択例 | 課題間の休憩 | 予定所要時間 |
|---|---:|---:|
| 改訂版 2 課題 | 各 60 s，計 1 回 | 13 分 |
| 旧版 2 課題 | 各 60 s，計 1 回 | 19 分 |
| 全 4 課題 | 各 60 s，計 3 回 | 33 分 |
| 改訂版 2 課題 | 0 s | 12 分 |

予定時間に開始前の説明・設定，一時停止時間は含めない．ブラウザの描画更新による遅れが加わる場合があり，実測の時間は予定時間と完全には一致しない．

## 刺激の表示と編集

### 表示

画面中央に刺激を大きく表示し，その上に「単語を考える」「動詞を考える」「頭の中で繰り返す」「休憩」などの区間名を表示する．課題画面の背景は白とする．休憩では＋を表示する．正誤フィードバックや音の合図は設けていない．

### ひらがなの初期リスト

| 課題 | 提示順 |
|---|---|
| 言語流暢性課題 | あ，か，き，さ，た，は |
| 言語流暢性課題（改） | あ，か，き，さ，た，は，な，ま，や，ら，み，こ |

### 名詞の初期リスト

| セット | 動詞生成に使う名詞 | 旧版の名詞反復に使う名詞 |
|---|---|---|
| 1 | りんご，ボール，自転車，はさみ，コップ | みかん，かばん，電話，靴，椅子 |
| 2 | 傘，鉛筆，時計，ドア，鍵 | ノート，タオル，皿，くし，窓 |
| 3 | 手紙，車，カメラ，電車，太鼓 | 本，飛行機，船，ギター，服 |
| 4 | ほうき，石鹸，布団，歯ブラシ，枕 | 雑巾，じょうろ，袋，タンス，靴下 |
| 5 | 卵，野菜，お茶，パン，ケーキ | ご飯，魚，水，コーヒー，肉 |
| 6 | パソコン，スマホ，テレビ，電気，ラジオ | リモコン，写真，電池，地図，扉 |

「刺激・構成」から，パターンごとに提示語を確認・編集できる．ひらがなは 1 文字ずつ，旧版は 6 個，改訂版は 12 個入力する．名詞は 6 行 × 各 5 個で入力する．数や形式が一致しない場合は保存できない．旧言語流暢性課題の無意味語も編集できる．

提示順は入力順であり，自動シャッフルはしない．「初期リストに戻す」は編集欄を初期値に戻す操作であり，「保存する」を押すと確定する．

初期リストは予備検証用であり，親密度や難易度を統制した標準刺激セットではない．旧版と改訂版で同じ刺激を使うため，連続実施時の重複も考慮する．実施時のリストは，全記録 JSON の `config.stimuli` に保存する．

## 回答方法と操作

参加者は，生成・反復のいずれも頭の中だけで取り組む．課題中の回答入力はない．実施者が使用する操作は以下である．

| 操作 | 内容 |
|---|---|
| 課題のチェック | 実行する課題を選択する． |
| 上下の矢印 | 課題の表示順・実行順を変更する．未選択の課題は実行しない． |
| 一時停止ボタン | 進行を停止する． |
| 再開ボタン | 一時停止した区間の残り時間から再開する． |
| Space キー | 一時停止・再開する．入力欄・ボタンの操作中は，各要素の標準操作を優先する． |
| Esc キー | 実行中は一時停止する．全画面の解除によっても停止する． |
| 全画面ボタン | 実行中に全画面へ切り替える． |
| 実施を中止 | 確認後，途中記録を保持して結果画面へ進む． |

## 表示・実施設定

| 設定 | 初期値・範囲 | 内容 |
|---|---|---|
| 実行する課題 | 改訂版の 2 課題 | 4 パターンから 1 つ以上選択する． |
| 実行順 | 言語流暢性課題（改）→ 動詞生成課題（改） | 上下の矢印で変更する．選択した課題だけに実行順番号を付ける． |
| 参加者 ID | 空欄，任意，80 文字以内 | イベント CSV と JSON に保存する． |
| 課題間の休憩 | 60 s，0〜600 s の整数 | 0 s で省略する．課題が 1 つの場合は追加しない． |
| 開始時に全画面で表示 | オン | 全画面に切り替えられない場合は通常表示で続ける． |
| 実行中に残り時間を表示 | オフ | 区間の残り時間と，一時停止を除く全体の経過時間を表示する． |
| セッションメモ | 空欄，任意，160 文字以内 | イベント CSV と JSON に保存する． |
| 刺激リスト | 上記の初期リスト | 各課題の「刺激・構成」から変更する． |

区間の秒数とセット数は，4 パターンの定義として固定する．実行中は課題の構成や提示語を変更しない．

## 一時停止・中止

### 一時停止

| 検出内容 | `reason` に記録する値 |
|---|---|
| 手動の一時停止・中止確認を開く操作 | `manual` |
| タブが非表示になった | `hidden` |
| ウィンドウからフォーカスが外れた | `blur` |
| 全画面表示を解除した | `fullscreen_exit` |
| 前回の描画更新から 1 s を超える遅れが生じた | `frame_delay` |
| 開始時に画面が非表示，またはフォーカスがない | `focus_lost` |

停止中は刺激を覆い，進行を止める．タブやウィンドウへ戻っただけでは自動再開しない．「再開する」を押すと，残り時間から続ける．中断した刺激を最初から出題し直す処理はしない．

停止を挟んだ区間は，その終了イベントに `interrupted = true` を記録する．一時停止イベント自体には `pause`，再開には `resume` を記録する．

### 中止

「実施を中止」を押すと一時停止し，確認画面を表示する．確認をキャンセルしても停止状態を維持する．中止を確定すると，その時点までのイベントを保持し，結果画面へ移動する．

未完了の区間は `phase_end` の `aborted = true` として記録する．課題内で中止した場合は `task_abort`，セッションの中止は `session_abort` を記録する．課題間休憩で中止した場合には，新たな `task_abort` を作成しない．

## 保存データ

| 保存ボタン | ファイル名 | 内容 |
|---|---|---|
| イベント CSV | `<session_id>_events.csv` | 課題・刺激・休憩の開始終了，一時停止，再開，中止と時刻 |
| 全記録 JSON | `<session_id>_record.json` | 実施設定，刺激リスト，全提示計画，イベント，状態 |

CSV は UTF-8 BOM 付き，カンマ区切り，CRLF 改行で出力する．各セルを二重引用符で囲み，値に含まれる二重引用符をエスケープする．表計算ソフトで数式と解釈される可能性がある文字列には，先頭にアポストロフィを付ける．JSON には元の文字列を保存する．

### イベント種別

| `event` | 内容 |
|---|---|
| `session_start` | 最初の刺激提示と同時点のセッション開始 |
| `task_start` | 各課題の最初の生成刺激の開始．開始した課題につき 1 行 |
| `phase_start` | 文字・名詞・無意味語・休憩など，各区間の開始 |
| `phase_end` | 各区間の終了 |
| `task_end` | 最後の休憩まで含む課題の完了 |
| `pause` | 一時停止 |
| `resume` | 手動による再開 |
| `task_abort` | 実施途中の課題の中止 |
| `session_abort` | セッションの中止 |
| `session_end` | 全予定区間の完了 |

### イベント CSV の列

イベント固有の項目は，該当しない行では空欄とする．

| 列名 | 内容 |
|---|---|
| `session_id` | セッション ID |
| `participant_id` | 参加者 ID．未入力の場合は空欄 |
| `session_note` | セッションメモ |
| `app_version` | アプリのバージョン |
| `event_index` | イベントの通し番号 |
| `event`，`event_label` | イベント種別と日本語の名称 |
| `timestamp` | UTC の ISO 8601 形式の時刻 |
| `timestamp_jst` | 日本時間の ISO 8601 形式の時刻 |
| `timestamp_unix_ms` | 同時点の UNIX 時刻，単位は ms |
| `wall_clock_unix_ms` | イベント時に別途取得する `Date.now()` の値 |
| `elapsed_ms` | セッション開始からの経過時間．一時停止を含む |
| `active_elapsed_ms` | 一時停止を除く経過時間 |
| `task_order` | 選択した課題のみを数えた実行順 |
| `task_id`，`task_name` | 課題の識別子と，画面と同じ正式名 |
| `task_family` | `verbal_fluency` または `verb_generation` |
| `protocol_version` | `original` または `revised` |
| `cycle` | 課題内のセット番号 |
| `condition` | 生成・反復・休憩などの条件 |
| `phase_index` | 課題間休憩を含む，全提示計画の区間番号 |
| `stimulus_index` | セット内の名詞番号．言語流暢性の生成・反復では 1，休憩では空欄 |
| `stimulus` | 提示した文字・名詞・無意味語，または＋ |
| `planned_onset_ms` | セッション開始を基準とした，区間の予定開始位置 |
| `planned_duration_ms` | 区間の予定時間．`task_start`・`task_end`・`task_abort` では課題全体の予定時間 |
| `onset_delay_ms` | 一時停止を除く経過時間と，予定開始位置との差 |
| `actual_duration_ms` | 区間終了時の実測時間．一時停止を除く．課題終了・中止ではその課題の実測時間 |
| `wall_duration_ms` | 区間終了時の実測時間．一時停止を含む |
| `overrun_ms` | 区間の実測時間と予定時間との差．一時停止を除く |
| `interrupted` | 停止を挟んだ区間の終了イベントで `true` |
| `aborted` | 中止によって終了した区間で `true` |
| `reason` | 一時停止の理由 |
| `pause_duration_ms` | 再開時に記録する，直前の停止時間 |
| `next_task_id` | 課題間休憩の開始イベントに記録する，次の課題の識別子 |

`condition` は，`word_generation`，`verb_generation`，`nonword_repetition`，`noun_repetition`，`rest`，`intertask_rest` のいずれかである．

**各課題の開始時刻を確認する場合は，`event = task_start` の行を抽出する．** `task_name` で旧版・改訂版を区別し，`task_order` と `timestamp_jst` を確認する．刺激の切り替え時刻は，`event = phase_start` の行から確認できる．

課題間休憩の行では課題の識別情報を空欄とし，`condition = intertask_rest` を記録する．課題開始・終了行に付随する `cycle` や `stimulus` などは，その時点で表示した区間の情報である．

## 時刻形式

| 列 | 記録例 | 意味 |
|---|---|---|
| `timestamp` | `2026-10-29T00:00:00.000Z` | UTC |
| `timestamp_jst` | `2026-10-29T09:00:00.000+09:00` | 同時点の日本標準時 |
| `timestamp_unix_ms` | `1793232000000` | 同時点の UNIX 時刻，単位は ms |

セッションを開始する直前の `Date.now() - performance.now()` を基準とし，`requestAnimationFrame` のコールバック時刻などを日時へ変換する．`wall_clock_unix_ms` は，OS 時計の補正などを確認できるように別途取得する値である．

`session_start` と最初の `task_start` は，開始ボタンを押した瞬間ではなく，最初の生成区間を開始した時点を記録する．課題ごとの開始時刻には `task_start` を使用する．ファイル名のセッション ID は識別用であり，厳密な開始時刻の代わりには使用しない．

イベント時刻はブラウザで表示を更新した時点の記録であり，ディスプレイの物理的な発光時刻を直接測定した値ではない．外部センサとの結合では，時刻形式と端末間の時計のずれを確認する．

## 端末内保存

| 保存キー | 内容 |
|---|---|
| `language-task-runner-settings-v1` | 課題の選択・順序，休憩，参加者 ID，メモ，表示設定，刺激リスト |
| `language-task-runner-record-v1` | 直近 1 セッションの設定，提示計画，イベント，状態 |

各区間開始，一時停止，再開，終了に合わせて記録を保存する．新しい本番を開始すると，直近の記録を上書きする．必要な CSV・JSON は次の本番の前に保存する．

再読み込み後は，保存済み記録の閲覧・出力に対応する．途中のセッションを再開する機能は設けていない．未完了の区間では終了イベントや終了時刻が確定していないため，「前回の途中記録」として扱う．

ブラウザの設定，保存容量，プライベートモード，ローカルファイルに対する実装の違いなどにより，保存できない場合がある．アプリが失敗を通知した場合は，終了画面から必ず記録をダウンロードする．実験記録をサーバーへ送信する処理は実装していない．

## データフロー

1. 実行する課題，順序，参加者 ID，課題間休憩，表示設定を確認する．
2. 必要に応じて刺激リストを編集する．
3. 開始前の説明を確認し，選択課題の提示計画を作成する．
4. 最初の生成刺激から計測を開始する．
5. 各課題の開始・終了と，各刺激・休憩の切り替えをイベントとして記録する．
6. 一時停止・再開・中止を記録し，進行中のスナップショットを端末内に保存する．
7. 完了または中止後に，課題ごとの開始時刻と実施状況を表示する．
8. イベント CSV と全記録 JSON を出力する．

## 原著と本アプリの設定

| 項目 | 参考にした内容 | 本アプリでの設定・変更 |
|---|---|---|
| 言語流暢性の生成時間 | Cai et al.（2013）の 15 s の内的単語生成 | 日本語のひらがなを視覚提示する． |
| 言語流暢性の反復条件 | 同研究の無意味語の内的反復 | 旧版では初期値を「ぱぬ」とする．改訂版は反復を外す． |
| 動詞生成の刺激間隔 | Allendorfer et al.（2012）の 6 s ごとの名詞提示 | 視覚提示した 5 名詞で 30 s とする．原著は音声提示である． |
| 動詞生成の対照条件 | 原著のブロック型課題では，音に合わせた両手の指運動 | 旧版は名詞の内的反復に変更し，改訂版は反復を外す． |
| 反復数・休憩・刺激リスト | 予備検証用に設定 | 本 README の 4 パターンを使用する． |
| 目的と測定指標 | 原著は fMRI による脳活動の評価 | 本アプリは提示時刻を記録し，外部の耳内温度計測などとの対応付けに使用する． |

「旧版」は本アプリを設計した際の旧構成を意味し，原著の完全な再現を意味しない．「改訂版」は，生成時間と休憩の合計を各 180 s にそろえた今回の構成である．日本語刺激の妥当性と，耳内温度の時間特性に適した課題時間は，この実装によって検証したものではない．

## 注意点

- 本番では発話・筆記・回答操作を求めないため，アプリの記録だけでは課題を遂行したことを確認できない．
- 刺激は初期案であり，単語の難易度や連想しやすさを統制していない．
- 旧版と改訂版の刺激が重複するため，比較時は実行順や反復による影響を考慮する．
- 課題の最後の休憩と，追加する課題間休憩は別の区間として扱う．
- 提示時間はブラウザの描画更新周期や端末の負荷の影響を受ける．実測時間と遅延はイベント CSV で確認する．
- 一時停止後は途中から再開するため，中断した区間を解析に含めるかは目的に合わせて判断する．
- 設定と直近の記録は，利用する端末・ブラウザ・保存元ごとに保持する．必要な記録は毎回ダウンロードする．
- アプリは脳活動や耳温の左右差を直接計測・判定しない．外部計測との対応付けには開始イベントと時刻を使用する．
