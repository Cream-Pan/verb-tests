GUIDE & RECORDS

使い方・記録仕様

  1. 実行する課題にチェックを入れ，矢印で順番を設定します．
  2. 参加者 ID と課題間の休憩時間を設定します．「刺激・構成」から提示語も確認できます．
  3. 開始前の説明を参加者と確認し，本番を開始します．
  4. 終了後にイベント CSV と全記録 JSON を保存します．

課題時間

言語流暢性課題：6 分 ／ 動詞生成課題：12 分
言語流暢性課題（改）：6 分 ／ 動詞生成課題（改）：6 分

各課題の最後の休憩も課題時間に含みます．課題間の休憩は別途追加します．開始前・終了後の安静や，計測中の追加説明はありません．

時刻と CSV

event = task_start が各課題の開始です．task_name に画面と同じ課題名，task_order に実行順を記録します．phase_start は各文字・名詞・休憩の開始です．

timestamp は UTC，timestamp_jst は日本時間，timestamp_unix_ms は UNIX 時刻のミリ秒です．elapsed_ms は停止時間を含む経過時間，active_elapsed_ms は停止時間を除く経過時間です．CSV は Excel 向けの UTF-8 BOM 付きです．

一時停止と記録の保管

タブの切り替え，ウィンドウからのフォーカス移動，全画面解除，描画の大幅な遅れで自動停止します．Space キーでも一時停止・再開できます．停止した刺激は途中から再開し，該当区間を interrupted = true と記録します．

設定と直近 1 回の記録は，この端末・ブラウザに保存します．サーバーへ実験記録を送信しません．ブラウザのデータ削除や端末故障に備え，実施ごとにダウンロードしてください．再読み込み後は未完了の計測を再開せず，残っている記録の出力に対応します．

計測上の位置付け

頭の中で生成した語の数や内容，課題の正誤は取得しません．時刻はブラウザで表示を更新した時点の記録であり，ディスプレイの物理的な発光時刻を保証するものではありません．長い描画遅延が発生しても，刺激を飛ばして時間を合わせる処理はしません．実際の提示時間と予定からの遅れを記録します．

本アプリは会話で設定した予備検証用プロトコルです．「旧版」も原著の完全な再現ではありません．
